# SONAR PSR-07 — Previous-draw median-state position marginals

**Status:** preregistered exploratory experiment; no engine promotion.
**Branch:** research/sonar-psr07-prior-median-state-20261108
**Isolation:** does not edit main or PR #6, #7, #8, or #13.

## Quantitative hypothesis

Let the previous draw's middle ordered statistic be \(M_{t-1}=P_3(t-1)\). The next draw's ordered-position marginal \(P_i(t)\) may be conditionally distributed differently by the theoretical quartile state of \(M_{t-1}\). Under independent uniform 5-subset draws, this state should add no predictive information; the experiment is designed to quantify whether a past-only empirical association survives proper scoring and out-of-sample inference.

The feature is fixed before scoring: it is the preceding draw's P3, never the target draw's P3. The four cutpoints are obtained from the exact order-statistic distribution, not from archive outcomes.

## Exact state and prior

For a uniform 5-subset of 1..40, the exact P3 marginal is

\[
\pi_3(m)=\frac{\binom{m-1}{2}\binom{40-m}{2}}{\binom{40}{5}},\quad m=3,\ldots,38.
\]

Theoretical quartile cutpoints are **15, 21, 26**, yielding states:
- \(M\le15\)
- \(16\le M\le21\)
- \(22\le M\le26\)
- \(M\ge27\)

The corresponding exact prior state masses are approximately 26.3869%, 28.5507%, 22.8243%, and 22.2380%.

For position \(i\), the exact order-statistic prior is

\[
\pi_i(n)=\frac{\binom{n-1}{i-1}\binom{40-n}{5-i}}{\binom{40}{5}},\quad n=i,\ldots,35+i.
\]

For a strict-prior training prefix, candidate state \(s_t\), and shrinkage \(\alpha\):

\[
q_{i,t}(n\mid s_t)=\frac{c_{i,t,s_t}(n)+\alpha\pi_i(n)}{N_{t,s_t}+\alpha}
\]

\[
q^G_{i,t}(n)=\frac{c_{i,t}(n)+\alpha\pi_i(n)}{N_t+\alpha}.
\]

The conditional candidate is compared against global position shrinkage with the **same alpha**, and against the exact order-statistic prior. Alpha grid: **100, 300, 1000**. Alpha is selected independently for each position by maximum validation mean Brier improvement over the same-alpha global comparator; ties choose the smaller alpha. Blind OOS is never used for tuning.

## Walk-forward protocol

- Canonical archive SHA pinned to Git blob 5d2efd70684e918b27d8f06386d545647898336d (3,401 draws through 2026-11-07).
- Warmup: target row index 300; 3,101 scored targets.
- Expanding strict-prior training: historical target rows \(j=2,\ldots,t-1\); expected training count \(t-2\). Each historical training target uses state from draw \(j-1\), and outcome from draw \(j\). The target feature is draw \(t-1\)'s P3.
- Chronological splits: discovery 50%, validation 25%, final blind OOS 25% (1,550 / 775 / 776 targets).
- Primary endpoint: paired Brier improvement (global comparator minus conditional model) per position in blind OOS.
- Inference: deterministic circular moving-block bootstrap, block length 7, 2,000 replicates; one-sided centered-null p-values and percentile 95% confidence intervals. Holm correction across the five predeclared primary position endpoints.
- Top-1, Top-5, log-loss, mean-rank, exact-prior comparisons, and state-frequency summaries are secondary/descriptive. They do not change the primary test family.

## Leakage, bias, and reproducibility controls

- Archive chronology, sorted unique 5-number rows, range 1..40, and pinned Git blob SHA are validated fail-closed.
- At each target, assert \(N_t=t-2\), last training target index \(t-1\), and cutoff date strictly before target date.
- Exact order-statistic prior normalization and candidate/global probability normalization are checked.
- Every target × position × alpha grid key must be unique; row counts must reconcile.
- Alpha selection is restricted to validation; blind OOS remains final and chronological.
- Fixed bootstrap seed and parameters; JSON, Markdown, and selected target ledger are deterministic.
- The historical blind slice overlaps previous SONAR research. It is not lab-wide independent confirmation. Marginal position outcomes are dependent; this is not a joint ticket model.
- No claim that Navier–Stokes physically governs lottery draws. This is a discrete conditional-statistics hypothesis inspired by residual/state modeling, not a physical velocity field.

## Decision rule and next action

No model is promoted. If no primary position survives Holm at 0.05, retain PSR-07 as a valid null/exploratory result and do not tune on the blind slice; the next substantive direction should be joint dependence diagnostics or a separately registered prospective shadow protocol. If any primary endpoint survives, retain the fixed candidate and require prospective append-only validation (minimum 200 paired targets) and human review before any promotion consideration.
