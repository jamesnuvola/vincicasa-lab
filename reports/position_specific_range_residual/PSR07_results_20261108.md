## Hypothesis and exact state

The preceding draw's P3 (middle order statistic) is a fixed, prior-only conditioning state for the next ordered-position marginal. Under independent uniform 5-subset draws it should not add predictive information.

\(\pi_3(m)=\binom{m-1}{2}\binom{40-m}{2}/\binom{40}{5}\), \(m=3,\ldots,38\).
Theoretical quartile cutpoints: **[15, 20, 26]**; exact state masses: **[26.3869, 23.6131, 27.762, 22.238]%**.

\(\pi_i(n)=\binom{n-1}{i-1}\binom{40-n}{5-i}/\binom{40}{5}\), \(n=i,\ldots,35+i\).
\(q_{i,t}(n|s)=[c_{i,t,s}(n)+\alpha\pi_i(n)]/[N_{t,s}+\alpha]\); global comparator uses the same \(\alpha\) and training rows.
Alpha grid: [100, 300, 1000]; chosen per position on validation only by maximum Brier improvement vs same-alpha global shrinkage. Tie: smaller alpha.
