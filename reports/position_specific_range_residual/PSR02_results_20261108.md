## Hypothesis / model

Previous draw odd-count state is fixed to bins 0–1, 2–3, 4–5. For each ordered position i:
\[
q_{i,t}(n\mid s)=\frac{c_{i,t,s}(n)+100\pi_i(n)}{N_{t,s}+100},\quad
\pi_i(n)=\frac{\binom{n-1}{i-1}\binom{40-n}{5-i}}{\binom{40}{5}}.
\]
Alpha=100 was fixed before the run. Comparator: global position-frequency shrinkage with the same prior, alpha and training target rows. Exact prior is also scored.
